# 모바일 반응형 대응

## 요청
- "webapp과 chat 모두 모바일에 전혀 대응을 하지 못하고 있는데, 모두 다 일반적인 해상도에
  반응 하는 반응형으로 제작 해줘"

## 진단
- webapp(`templates/base.html`)에 `<meta name="viewport">` 태그가 아예 없었음. 기존
  `static/style.css`에 `@media (max-width: 768px)` 규칙이 있었지만 viewport meta가 없으면
  모바일 브라우저가 데스크톱 폭(~980px)으로 그린 뒤 축소 표시하므로 미디어 쿼리가 발동하지
  않음 — "전혀 대응 못함"의 근본 원인.
- 그 규칙조차 사이드바를 `display:none`으로만 숨기고 대체 내비게이션이 없어 좁은 화면에서
  카테고리 이동이 아예 불가능한 구조였음.
- chat(Next.js 16.2.12 App Router)은 viewport meta가 기본 자동 삽입됨을
  `node_modules/next/dist/docs`에서 확인(`chat/AGENTS.md`가 이 버전은 학습 데이터와 다를 수
  있으니 문서를 먼저 읽으라고 지시). 대신 `min-h-screen`(100vh)이 모바일 주소창/키보드에 따라
  실제 화면보다 크게 잡히는 문제, 도구 호출 JSON 텍스트가 공백 없이 길어 가로 스크롤을
  유발하는 문제를 발견.

## 행동
1. 이전 세션이 쓰던 `plan.md`/`checklist.md`/`context-notes.md`(2단계 구조화 DB 작업용, 일부
   미완 항목 있음)를 `*-stage2-structured-db.md`로 이름 변경해 보존, 이번 작업 전용으로 새로
   작성.
2. `templates/base.html` — viewport meta 추가, 햄버거 버튼(`#nav-toggle`)/백드롭
   (`#sidebar-backdrop`) 마크업 + 순정 JS 토글 스크립트 추가.
3. `static/style.css` — 모바일 사이드바를 `display:none`에서 `position:fixed` 슬라이드인
   드로어로 전환. 추가로 ≤640px에서 속성/표 라벨(`.row`)을 세로 스택, 항목 생성/수정 폼
   (`.form-row`/`.form-table-block`)을 단일 컬럼으로, `category-grid`/`backlink-list`의
   grid `minmax`를 좁은 화면용으로 축소. `.shell`의 `height:100vh`가 모바일에서
   `overflow:hidden`과 겹쳐 콘텐츠를 잘라먹는 문제도 `height:100dvh` 폴백으로 수정.
4. `chat/app/page.tsx` — `min-h-screen` → `min-h-dvh`, 도구 호출 `<summary>`와 메시지 버블에
   `break-all`/`break-words` 추가(가로 스크롤 방지).
5. 검증: Flask test_client로 홈/카테고리/상세/생성/수정/`/assistant` 6개 경로 200 확인 +
   렌더링 결과에 viewport meta/nav-toggle 마크업 포함되는지 assert. `npm run build`,
   `npm run lint` 통과 확인.

## 결정
- 데스크톱 레이아웃/디자인은 그대로 두고 `@media (max-width: ...)` 안에서만 오버라이드하는
  기존 코드 관례를 그대로 따름.
- 사이드바를 완전히 숨기는 대신 드로어 방식을 선택 — 별도 JS 프레임워크 없이 순정 JS로
  클래스 토글만 처리(서버 렌더 MPA라 페이지 이동 시 자연히 닫힘).
